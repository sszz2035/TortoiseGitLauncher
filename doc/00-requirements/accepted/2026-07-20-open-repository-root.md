# 在文件资源管理器中打开仓库根目录

## 背景

用户在快捷面板中切换仓库后，需要快速进入当前仓库根目录查看或操作文件。

## 目标

在“仓库根目录”标题右侧提供“打开根目录”按钮，点击后使用 Windows 文件资源管理器打开当前选中的仓库根目录。

## 范围

- 按钮跟随仓库下拉框的当前选择。
- 打开成功后在状态栏显示目标路径。
- 未选择有效仓库、目录不存在或启动失败时，使用状态栏和消息框给出明确提示。

## 不做什么

- 不改变当前工作目录。
- 不修改仓库列表或仓库历史数据格式。
- 不新增或调整 TortoiseGit 命令映射。

## 验收标准

- 按钮显示在“仓库根目录”标题右侧，视觉样式与现有操作按钮一致。
- 选择有效仓库后点击按钮，文件资源管理器打开该仓库根目录。
- 当前仓库无效或目录不可访问时不启动文件资源管理器，并显示错误信息。
