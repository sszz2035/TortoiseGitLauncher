# 资源管理器右键添加目录

## 交互

- 文件夹及文件夹背景右键菜单提供“添加到仓库管理”和“添加到脚本执行”。
- 软件未启动时启动软件；已启动则转交同一用户及 Windows 会话中的现有窗口。
- 两模块均弹框选择目标目录页，默认选中本模块上次使用的页。取消不添加；确认保存后切页并选中该目录。
- 仓库子目录解析至 Git 根目录；非 Git 目录拒绝导入。脚本目录接受普通文件夹。

## 细则

- 保存绝对路径，页内重复选中原项，不覆盖名称、备注、分组和顺序；其他页可存在相同路径。
- 新目录作为未分组项追加到目标页末尾。使用既有编辑副本和先保存后应用边界，失败不替换活动数据，不改变配置格式、全局脚本或运行实例。
- 连续请求排队；存在列表管理等模态窗口时等待关闭，避免旧副本覆盖新导入项。
- 启动默认注册当前用户菜单；侧边栏可启用/更新或移除，移除后重启不自动恢复。仅写 HKCU 下本软件菜单及偏好，无需管理员权限。
- 首次使用前需启动新版本一次；移动程序后在新位置启动更新注册。Windows 11 下可能位于“显示更多选项”。
- 仅处理单目录，不新增 Windows 11 原生菜单 COM 扩展，不自动执行脚本或 Git 命令，不支持跨 Windows 会话转发。

## 验收

- 两种右键入口、两模块和多页独立选择；关闭、打开、最小化状态的启动或转发。
- 中文/空格/磁盘根目录；Git 子目录及工作树；失效目录与非 Git 目录提示。
- 取消、重复添加、保存失败不损坏已有内容；模态编辑与连续请求不互相覆盖。
- 移除后重启保持禁用，重新启用有效，不影响其他软件菜单。
