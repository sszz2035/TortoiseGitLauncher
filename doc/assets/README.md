# 资源文件区

这里存放文档和设计讨论用到的资源文件。资源可以服务于需求说明、UI 设计、问题复现和架构说明。

## 目录约定

- `images/`：通用图片素材
- `screenshots/`：界面截图、问题复现截图
- `diagrams/`：流程图、架构图、草图
- `icons/`：图标、候选图标、视觉参考
- `references/`：外部参考资料、说明截图、竞品参考

## 使用建议

资源文件命名要能看出用途，优先使用英文短横线命名，例如：`command-panel-clipped-button.png`。

重要资源应在相关需求或说明文档里引用，避免只把文件丢进目录却没有上下文。
