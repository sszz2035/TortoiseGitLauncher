# 页面扩展指南

## 当前页面结构

左侧“功能导航”当前包含两个入口：

- `仓库管理`：现有仓库选择和 TortoiseGit 命令页面。
- `脚本执行`：自定义脚本功能页面，代码位于 `Features/ScriptRunner/`。

主窗体创建页面实例后统一放入页面宿主容器，通过显隐和层级切换页面。页面切换时不销毁实例，确保脚本执行页后续可以在离开页面后继续维护运行状态和输出。

## 页面职责

- `UI/MainForm.cs` 负责导航按钮、页面宿主和页面切换。
- `UI/MainForm.RepositoryManagement.cs` 负责仓库管理页面的布局与交互。
- `Features/ScriptRunner/ScriptRunnerPage.cs` 负责脚本执行页面的布局与交互。
- 页面内部的持久化和进程生命周期应继续下沉到 feature 内的独立类型，不能放回主窗体。

## 目录页与功能页的区别

目录页位于两个已有功能页内部，不新增左侧导航入口。共享的 `DirectoryPageSelectorButton` 提供标题菜单，`DirectoryPageManagerForm<TPage>` 管理页编辑副本；仓库逻辑在 `MainForm.DirectoryPages.cs`，脚本逻辑在 `ScriptRunnerPage.DirectoryPages.cs`。

每次切换先保存候选配置，成功后才刷新当前页目录列表与选择。仓库备注须先成功保存；脚本切页保留原页面与运行器，不销毁运行实例。当前页目录列表编辑也通过保存回调处理，失败时保留对话框供重试。

## 同模块跨页编辑事务

两个目录列表管理窗口各自持有本模块全部目录页的深克隆；“移动到…”、“复制到…”列出同模块的其他页，仓库管理另外允许选择脚本执行模块的页，不提供跨页拖放。选择普通项时追加到目标未分组区；整组包含折叠子项，生成新组标识，同名组加编号，保留展开状态与子项顺序。转移之前应用当前名称输入，重复路径跳过且不覆盖目标，部分移动只从源页移除成功项。

共享规则位于 `DirectoryPageTransfer`，通过最小条目/分组协议复用；服务先校验并准备所有新增项，再修改副本，不做磁盘操作。目标顶层新内容按混排顺序追加，不重排已有配置。结果显示新增/跳过目录数、分组数、自动改名与跳过路径明细。

保存回调通过管理器 `GetPages()` 获取全部页，校验路径唯一性、组名与归属后由现有安全配置保存流程一次落盘；成功才替换活动状态。取消放弃源页、所有目标页修改；保存失败保持编辑窗口供重试。模态管理窗口期间不能从主界面再打开其他相关管理事务。脚本配置及进程实例不在此次页编辑副本内。

## 仓库到脚本执行的单向转移

仓库列表管理窗口额外持有所有执行目录页副本。共享目标选择器先选模块，再选目录页；仓库源排除本仓库页，脚本源仍仅提供本模块的其他页。RepositoryToScriptTransfer 将仓库路径、名称、备注及组状态映射成执行目录类型，再复用既有转移规则；不检查真实路径可用性或 Git 身份，不复制脚本。

主窗体只协调保存边界：脚本页通过 CloneDirectoryPages 提供快照，ApplyTransferredDirectoryPages 使用当前全局脚本配置保存并刷新原页面，保持当前目录页与运行器。源、目标在点击“保存修改”前都只修改副本，取消全部放弃。

涉及跨模块变更时，DirectoryTransferSave 先保存目标，再保存源；目标失败不尝试保存源。目标成功而源失败时，目标已生效、磁盘源仍保留；窗口锁定编辑，仅允许重试保存或确认关闭。重试使用同一副本并跳过已完成的目标保存，不重新导入分组。确认关闭后保留已保存目标、放弃源编辑；中断后可从原源配置和两文件的备份恢复，不自动删除源。两文件不宣称原子提交。

## 新增页面建议

新增页面时，应先定义页面职责，再确认：

- 导航入口和选中状态。
- 页面实例是常驻还是按需创建。
- 页面切换后的后台任务生命周期。
- 页面间需要共享的最小状态。
- 数据读写和错误呈现边界。
- 窗口最小尺寸、高 DPI 和滚动范围。
