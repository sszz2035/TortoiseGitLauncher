# UI 布局规则

## WinForms 布局注意事项

- 使用 `AutoSize` 时必须确认父容器能被子控件撑开。
- `FlowLayoutPanel` 开启 `WrapContents` 后，要验证换行后的高度。
- 固定尺寸按钮要预留下边距，避免被下一块内容裁剪。
- 高 DPI、窗口缩放和最小窗口尺寸都要纳入布局检查。
- 不要长期依赖子控件临时 `Bottom` 坐标作为容器高度来源；窗口最小化、缩小、恢复时这些坐标可能对应旧布局。
- 自动尺寸容器需要显式设置 `AutoSizeMode = GrowAndShrink`，否则窗口缩小再恢复后可能保留旧高度，导致滚动范围出现大块空白。
- 外层 `AutoScroll` 容器需要在内容布局变化后同步 `AutoScrollMinSize`，并把滚动位置夹回当前内容高度范围内。

## 已沉淀问题

命令按钮换行后，卡片高度曾未正确撑开，导致第二行按钮被裁剪。后续修复发现，直接使用子控件 `Bottom` 同步高度会在窗口缩小再恢复后留下异常空白；当前做法是按 `FlowLayoutPanel` 的可用宽度、按钮宽度和边距重新计算行数与总高度，让外层自动尺寸容器使用 `GrowAndShrink`，并同步 `AutoScrollMinSize` 收回旧滚动高度。
