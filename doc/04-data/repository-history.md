# 仓库历史数据

## 存储位置

仓库列表保存在本机用户目录下的 TortoiseGitLauncher/recent-repos.json。

## 当前版本结构

当前版本为 3，使用目录页结构。顶层字段为 `Version`、`Pages`、`LastSelectedPageId`。

每个 `Pages` 条目包含 `Id`、`Name`、`DisplayOrder`、`LastSelectedDirectoryPath`，以及本页的 `Groups` 与 `Entries`。页标识稳定，每页独立去重，不跨页去重。下表中的 Groups/Entries 已迁入页内，不再位于顶层。

界面通过 `[JsonIgnore]` 兼容属性访问当前页；点击“仓库根目录 · 页名”切页或打开“管理目录页”，支持新建、重命名、排序和删除。仅 `Pages` 写入 JSON，不再双写旧版列表。页切换与页管理先保存编辑副本，成功后才替换活动状态；失败保留编辑内容。页管理取消不改变原配置。

每页保存自己的选中路径，启动时只在最后选中页的现有条目中恢复；已移除或不可用时选择本页第一个可用条目，没有则保持无选择。读入新版 `Pages` 后禁用启动目录自动加入，避免空页被填充或删除项复活；只有首次初始化或旧格式迁移可使用启动目录回退。删除页须确认且至少保留一页，不删除真实目录。

旧版本 2 的顶层对象包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Version | 整数 | 配置结构版本 |
| Groups | 数组 | 用户创建的一级仓库组，按 DisplayOrder 显示 |
| Entries | 数组 | 仓库普通元素，按 DisplayOrder 保存 |

### 仓库组

每个 Groups 条目包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Id | 字符串 | 稳定 GUID 标识 |
| Name | 字符串 | 组名称 |
| DisplayOrder | 整数 | 顶层组顺序 |
| IsExpanded | 布尔值 | 下拉框和管理界面的展开状态 |

组只支持一级结构，不保存“未分组”虚拟组。组名称在同一列表内应保持唯一。

### 仓库条目

每个 Entries 条目包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| DisplayName | 字符串 | 用户自定义显示名 |
| RepoRootPath | 字符串 | 规范化后的仓库根目录路径 |
| Notes | 字符串 | 按仓库目录保存的备注，默认空字符串，保留换行与空格 |
| GroupId | 字符串或空 | 所属组的稳定 GUID；为空表示未分组 |
| DisplayOrder | 整数 | 统一保存顺序；界面按归属重新组织显示 |

仓库路径按不区分大小写的方式去重。无效路径仍保留配置，交由界面标记和处理。

备注属于仓库目录，与分支无关。切换分支不更换备注；重命名、分组和排序通过 `Clone()` 保留备注，删除仓库条目同时删除备注。旧配置缺少 `Notes` 或值为 `null` 时按空字符串读取，仍兼容版本 2 的读取；同一路径在不同页的备注互相独立。

仓库管理页备注停止输入 500 毫秒后自动保存；离开输入框、切换仓库、打开列表管理或关闭窗口时立即保存待写入内容。保存失败会提示并保留内存修改，阻止切换仓库、打开列表管理及关闭窗口，避免丢失尚未保存的备注。

当前分支不保存到配置。选择仓库、返回仓库管理页和窗口重新激活时，在后台读取工作目录的 `.git/HEAD`；支持 `.git` 文件定位的 worktree 和子模块。尚无提交时仍显示分支名称，游离 HEAD 显示短提交号；目录失效或读取失败显示状态提示。分支名称本身不依赖 Git 命令行，不修改仓库文件。最新更新时间另用本机 Git 的只读 `rev-parse` 和 `show --format=%cI` 查询 HEAD 提交的提交者时间，以本机时区显示；不保存到配置，不代表文件修改、网络拉取或本次操作时刻。页面可见时每两秒检查分支与时间，隐藏页面停止轮询；Git 不可用、无提交或读取失败显示明确状态。

## 同模块跨页移动与复制

“管理仓库列表”持有所有仓库页的独立副本；移动/复制先在副本中执行，点击“保存修改”才将源页和涉及的目标页一次写入同一配置文件，取消全部放弃，失败保留副本。保存前检查页内规范化路径去重、组名称唯一性与条目归属，不依赖存储层静默裁剪来消除转移错误。

普通项追加到目标未分组区并保留显示名、绝对路径与备注；整组生成新的稳定标识，同名自动加编号，保留折叠状态与子项顺序。目标整页已有路径均跳过，目标元数据不覆盖；移动中被跳过的项留在源页/源组。源组全部成功移走才删除，全部重复不创建目标空组，原始空组允许转移。目标原有顺序不变。

## 单向转移到脚本执行

仓库目录项与组可移动或复制到脚本执行的指定页；RepoRootPath 映射为 DirectoryPath，保留显示名称、备注和顺序，组沿用跨页去重、自动改名与部分移动规则。只操作配置，不搬动真实仓库。

管理窗口持有两模块页副本，保存前取消不落盘。保存时先安全写入脚本配置，再写仓库配置；目标写入失败不会尝试写源。目标成功、源失败时原源文件仍保留，窗口锁定编辑并允许重试，重试不会重复创建目标分组。关闭需明确确认目标已保存且不会撤销；确认后只放弃源编辑。两配置保留各自 .bak，发生中断时以保留源为优先，不自动补做删除；没有跨文件原子提交或自动恢复事务日志。

## 旧版本迁移

旧版本配置是字符串数组或仓库对象数组。读取时：

- 旧字符串数组、对象数组及版本 2 分组列表统一迁移到版本 3 的单个“默认页”；版本 2 的原有分组与归属不变。
- 没有分组的旧数组项归入未分组；有分组的对象结构不清空分组。
- 保留显示名、规范化路径和原数组顺序。
- 不自动创建用户组。
- 当前选中仓库仍按路径恢复。
- 首次保存后写入新的对象结构。

如果普通条目的 GroupId 无法关联现有组，则恢复为未分组；重复或无效组标识会隔离修复，不影响其他条目。

## 读写规则

- 文件不存在时使用空配置。
- 读取单个坏组或坏仓库项时跳过该项，不影响其他项。
- 保存时写入 UTF-8 无 BOM。
- 保存失败不让应用崩溃。
- 保留组和条目的 DisplayOrder，避免把顶层组与未分组项的混合顺序重新排乱；页面顺序归一化。
- 读取不写文件；首次保存旧配置时，备份到 `.v{旧版本}.bak`（旧数组按版本 0），后续原子替换前保留上一版 `.bak`。
- 保存使用独立临时文件、Flush(true) 和 File.Replace；新文件使用 File.Move，写入失败不截断正式文件。
- 未知未来版本、无法解析或新版缺少目录页集合时，返回带 SaveBlockedReason 的配置，禁止后续空数据覆盖；保存时也复核磁盘版本。
- 单个坏页跳过并警告，其他有效页继续读取；新版没有任何可恢复页时禁止覆盖原文件。
