# 脚本执行配置数据

## 存储位置

脚本执行功能使用独立配置文件：

```text
%LOCALAPPDATA%\TortoiseGitLauncher\script-runner.json
```

该文件不修改现有 `recent-repos.json` 的格式。

## 当前版本

当前版本号为 `1`。任务 2 已包含以下字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `Version` | 整数 | 配置结构版本 |
| `RecentDirectories` | 数组 | 最近执行目录，最多保留 20 项 |
| `LastSelectedDirectoryPath` | 字符串 | 上次选择的执行目录绝对路径 |

每个 `RecentDirectories` 条目包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `DisplayName` | 字符串 | 用户自定义显示名，可以为空 |
| `DirectoryPath` | 字符串 | 规范化后的绝对路径 |

后续脚本配置字段继续加入同一 feature 配置，但必须保持现有目录字段兼容。

## 读写规则

- 文件不存在时使用默认配置。
- 使用 UTF-8 无 BOM 写入。
- 保存时先写临时文件，再替换正式文件。
- 单个目录条目损坏时跳过该项，不影响其他条目。
- 目录路径去重时忽略大小写。
- 路径不存在时保留配置，由界面标记为不可用。
- 整个文件无法解析时使用默认配置，并在页面显示警告。
- 保存失败时不让应用崩溃，并在页面和消息框显示错误。

## 初始目录优先级

进入脚本执行页面时按以下顺序选择可用目录：

1. 上次选择的执行目录。
2. 主窗体初始化时的当前仓库根目录。
3. 程序启动目录。
4. 最近目录列表中的第一个可用目录。

仓库根目录只作为首次初始化回退值传入，之后仓库选择和脚本执行目录相互独立。
