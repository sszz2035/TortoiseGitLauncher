# 脚本执行配置数据

## 存储位置

脚本执行功能使用独立配置文件：

```text
%LOCALAPPDATA%\TortoiseGitLauncher\script-runner.json
```

该文件不修改现有 `recent-repos.json` 的格式。

## 当前版本

当前版本号为 `4`。顶层字段为 `Version`、`Pages`、`LastSelectedPageId` 和全局 `Scripts`。脚本配置不按页复制。

每个页包含 `Id`、`Name`、`DisplayOrder`、`LastSelectedDirectoryPath`、`DirectoryGroups`、`RecentDirectories`。每页独立去重、分组和保存选择；同一路径可出现在不同页。界面通过 `[JsonIgnore]` 兼容属性访问当前页，点击“执行目录 · 页名”切页或管理页。页管理支持新建、重命名、排序和删除，取消放弃编辑；至少保留一页。

切页及管理页、目录列表时先保存编辑副本，成功后才替换内存状态；保存失败保留窗口与输入以便重试。页切换不重建脚本运行器和实例标签页；脚本配置保持全局共享，已有实例继续使用启动时的执行目录。

下表为旧版本 3 结构；目录字段现迁入各页，仅 Scripts 继续位于顶层：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `Version` | 整数 | 配置结构版本 |
| `DirectoryGroups` | 数组 | 用户创建的一级执行目录组，按 DisplayOrder 显示 |
| `RecentDirectories` | 数组 | 执行目录列表，不再设置数量上限 |
| `LastSelectedDirectoryPath` | 字符串 | 上次选择的执行目录绝对路径 |
| `Scripts` | 数组 | 全局共享的脚本配置，按 `DisplayOrder` 显示 |

### 执行目录组

每个 DirectoryGroups 条目包含 Id、Name、DisplayOrder 和 IsExpanded，分别表示稳定 GUID、组名称、顶层顺序和展开状态。组只支持一级结构，不保存“未分组”虚拟组；组名称在执行目录列表内应保持唯一。

### 执行目录条目

每个 `RecentDirectories` 条目包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `DisplayName` | 字符串 | 用户自定义显示名，可以为空 |
| `DirectoryPath` | 字符串 | 规范化后的绝对路径 |
| `Notes` | 字符串 | 目录项备注，默认空；保留跨模块导入数据，暂不新增编辑区 |
| `GroupId` | 字符串或空 | 所属组的稳定 GUID；为空表示未分组 |
| `DisplayOrder` | 整数 | 保存顺序 |

### 脚本配置条目

每个 `Scripts` 条目包含：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `Id` | 字符串 | 稳定的 GUID 标识；缺失、无效或重复时读取端会生成新标识 |
| `Name` | 字符串 | 用户可修改的脚本名称；缺失时从文件名生成 |
| `ScriptPath` | 字符串 | 脚本文件绝对路径 |
| `ScriptType` | 字符串枚举 | `Python`、`Batch`、`Command` 或 `PowerShell` |
| `Arguments` | 字符串 | 原始命令行参数文本，可以为空 |
| `IconKey` | 字符串 | 内置图标稳定键；当前仅支持 `default-script` |
| `DisplayOrder` | 整数 | 显示顺序，保存时归一化为从 0 开始的连续序号 |

脚本类型以文件扩展名为准，只接受 `.py`、`.bat`、`.cmd` 和 `.ps1`。脚本文件后来失效时仍保留配置，不在读取阶段删除。

## 读写规则

- 文件不存在时使用默认配置。
- 使用 UTF-8 无 BOM 写入。
- 保存时写独立临时文件、Flush(true)，再用 File.Replace 替换并保留 .bak；首次迁移另保留 .v{旧版本}.bak。
- 单个目录或脚本条目损坏时跳过该项，不影响其他条目。
- 目录路径在每页内忽略大小写去重，不跨页去重；读入、保存及页面新增均不再静默截断 20 项。
- 目录和脚本路径不存在时保留配置，由界面标记为不可用。
- 未识别的图标键回退到 `default-script`。
- 脚本列表按 `DisplayOrder` 读取，并在保存时重新生成连续顺序。
- 整个文件无法解析、新版缺少目录页或版本高于支持值时显示警告并阻止保存，避免空配置覆盖原文件；单个坏页不影响有效页。
- 保存失败不让应用崩溃，并在页面和消息框显示错误。

## 同模块跨页移动与复制

“管理目录列表”支持选中普通项或分组，通过“移动到…”、“复制到…”选择其他执行目录页。与仓库列表使用同一个转移服务：普通项放入目标未分组区，整组保留展开状态与组内顺序并生成新标识，同名组加编号；目标页内任意位置的重复路径均跳过，移动时重复项保留在源页，备注随克隆保留。

管理窗口持有全部执行目录页副本，保存时统一校验并安全写入；取消放弃所有源、目标变更，失败保留编辑内容。当前页保存不额外重排目标原有条目；转移不复制全局脚本，不重建运行器或终止运行实例，不触碰真实目录。

## 接收仓库管理目录

仓库列表的“移动到…”、“复制到…”可选择脚本执行的任意目录页；执行目录列表不提供反向入口。目标使用独立页副本，保留已有条目元数据，整页重复路径跳过，同名组新建并自动编号。接收 Notes 字段但不新增备注编辑区。

正式保存先写脚本执行配置，成功后才允许写入已移除成功项的仓库配置。目标失败不删源；源失败时脚本侧已刷新，源原文件保留，仓库编辑窗口锁定并提示重试或确认关闭。重试不再次导入或重写目标；源原文件与各自备份可供中断后恢复。取消仅能放弃未保存内容，部分提交后的已保存目标不会被隐式回滚。

脚本侧只暴露目录页快照与保存入口；保存时克隆当前配置，替换页集合，保留当前目录页、全局脚本与同一运行器。切页或目录配置变化不影响已有实例的启动目录、输出或状态。不升级配置版本。

## 版本兼容

- 版本 1–3 的目录集合完整迁入版本 4 的“默认页”，保留分组、归属、名称、选择与原有 DisplayOrder；脚本列表仍只有全局一份。
- 新版已存在 Pages 时不再合并旧字段，防止已删除目录再次出现；没有任何可恢复页时阻止覆盖。

- 版本 1 没有 `Scripts` 字段；版本 2 读取时将缺失字段视为空脚本列表。
- 版本 2 没有 DirectoryGroups、GroupId 和目录顺序字段；读取时全部目录迁移为未分组，并按原数组顺序补充顺序。
- 缺少可推导的脚本名称、类型、图标或唯一标识时，读取端补充明确默认值。
- 缺少脚本路径、使用相对路径或扩展名不受支持的条目无法安全恢复，因此只跳过该条目。

## 初始目录优先级

已有新版目录页时，只在当前页内恢复上次选中项，否则选择本页第一个可用目录；没有可用目录则保持无选择，禁用脚本执行和打开根目录。路径失效仍保留配置。恢复选择不通过新增条目实现，不会复活已删除的项。

仅首次初始化或旧格式迁移且当前页没有可用条目时，才允许将主窗体初始仓库目录或启动目录加入默认页。新版配置、新建空页和切换页不使用此回退。

首次初始化的回退顺序为：

1. 当前页中已存在的上次选择目录，或本页第一个可用目录。
2. 主窗体初始化时的当前仓库根目录（仅允许初始化回退时）。
3. 程序启动目录（仅允许初始化回退时）。

仓库根目录只作为首次初始化回退值传入，之后仓库选择和脚本执行目录相互独立。
