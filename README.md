# TortoiseGit 快捷面板

这是一个简单的 Windows 图形工具。

界面已经拆成“左侧导航 + 右侧页面”结构，当前只有一个页面：`仓库管理`。后续扩展功能时，可以继续往侧边栏增加新页面。

用法：

1. 在任意目录中打开 PowerShell 或 `cmd`。
2. 运行这个工具的 `exe`。
3. 如果当前目录位于 Git 仓库内，程序会自动定位到对应的仓库根目录。
4. 也可以点击“选择仓库目录”，任选一个位于 Git 仓库中的目录，程序会自动转换成对应的仓库根目录。
5. 点击仓库根目录标题旁的“打开根目录”，可以在文件资源管理器中打开当前仓库根目录。
6. 通过“管理仓库列表”可以修改下拉框内容：
- 重命名显示名（不改原路径）
- 上移 / 下移调整顺序
- 删除单个条目
7. 修改后的显示名和顺序会保存，下次启动仍然生效。

当前提供的按钮包括：

- 提交
- 日志
- 同步
- 拉取
- 推送
- 切换/检出
- 清理
- 仓库状态
- 还原
- 解决冲突
- 获取
- 贮藏
- 弹出贮藏

仓库列表默认保存在：

`%LOCALAPPDATA%\TortoiseGitLauncher\recent-repos.json`

构建：

```powershell
.\build.ps1
```

构建完成后，可执行文件默认输出到 `.\dist\TortoiseGitLauncher.exe`。
