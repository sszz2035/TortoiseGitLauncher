# 目录页数据回归检查

独立的 .NET 9 控制台测试，无第三方测试包；直接链接生产模型及存储源码，不加载 WinForms、不读写本机用户配置。

仅在用户授权编译或运行测试后执行：

```powershell
dotnet run --project tests/DirectoryPages/DirectoryPages.csproj
```

覆盖旧分组配置迁移、旧数组、32 项不截断、页内/跨页数据隔离、全局脚本、选择恢复、迁移与上次保存备份、未来版本保护、坏页隔离和 UTF-8 无 BOM。任务 2 补充已删除路径不复活、失效路径不选中、空页保留、启动回退边界及编辑副本取消隔离；2026-11-09 随最终回归执行通过。

任务 3 新增 `DirectoryPageTransferTests.cs`：普通项追加顺序、独立备注、大小写/尾分隔符/路径归一化去重、部分移动、折叠组与空组、同名编号、全部重复无变更、完整组移除、取消隔离、保存重载、保存失败保留、执行目录同策略及全局脚本不复制、非法归属与同页转移拒绝。这些用例于 2026-11-09 随最终回归编译并运行通过。

样例配置全部写入系统临时目录 `TortoiseGitLauncher-tests-{GUID}`，结束时输出位置并保留供排查。测试不修改真实目录文件，不触发 Git 操作。

`DirectoryPages.Windows/DirectoryPages.Windows.csproj` 是额外的 Windows/.NET 9 WinForms 组件与进程集成检查：

```powershell
dotnet run --project tests/DirectoryPages.Windows/DirectoryPages.Windows.csproj
```

它直接链接生产窗体、存储、目录转移与脚本进程类型；用反射驱动窗体和控件，不实例化主窗体，不读写真实用户设置。测试将布局快照、文件锁、两份配置重载及临时脚本写入系统临时目录。包含独立新进程重载、仓库/执行目录编辑副本与取消、保存重试、双配置移动失败恢复、长页名、按钮边界/模拟 DPI 缩放、两个脚本并发输出隔离、自动结束和终止实例。需要 Windows 桌面运行环境。
